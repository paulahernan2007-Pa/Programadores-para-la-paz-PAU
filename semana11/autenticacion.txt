El login es el proceso que permite identificar a un usuario antes de acceder a una aplicación. Gracias al inicio de sesión, cada persona puede usar las funciones que le corresponden. Algunas rutas deben estar protegidas para evitar que usuarios no autorizados accedan a información o realicen acciones importantes. Esto ayuda a mantener la seguridad y la privacidad de la plataforma. No se deben exponer públicamente contraseñas, documentos de identidad, teléfonos, direcciones, tokens, claves de API ni otros datos sensibles de la comunidad.
